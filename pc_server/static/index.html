フロー較正(純回転フィット) TLM_STATE 25Hz → 2×2 K 行列

手順: ①モーター停止・プロペラ静止を確認 ②テクスチャのある床/机の上 0.15〜0.5m(ToF 有効域)で機体を手持ち ③ロール/ピッチを ±20〜30° でゆっくり 20〜30秒ゆらす (ヨー回転と並進は極力入れない)。
軸規約: trans_x = flow_x − q / trans_y = flow_y + p(機体 x=前 / y=右)。 K は「機体系レート [rad/s] → カウントレート [counts/s]」の写像で、機上は rate = K⁻¹·counts を適用します。
参考 — 未較正時の実測: スケール約 1.11/1.26 倍過大・取付回転 −9.4° (docs/FLIGHT_ANALYSIS_20260731.md §5)。
